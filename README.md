### Descripción del proyecto
Software FJ es una aplicación desarrollada en Python que permite gestionar clientes, servicios y reservas mediante programación orientada a objetos.

El sistema busca garantizar una gestión organizada, estable y segura, mediante validaciones y manejo de excepciones que permiten controlar los errores durante su ejecución.

### Funcionalidades
- Registro y validación de clientes.
- Gestión de reservas de salas.
- Alquiler de equipos.
- Gestión de asesorías especializadas.
- Confirmación y cancelación de reservas.
- Cálculo de costos con descuentos e impuestos.
- Manejo de excepciones personalizadas.
- Registro de errores y eventos mediante archivos LOG.

### Conceptos de programación aplicados
- Abstracción.
- Herencia.
- Encapsulación.
- Polimorfismo.
- Clases abstractas.
- Manejo de excepciones.
- Listas internas.
- Validación de datos.

### Tecnologías utilizadas
- Python 3.
- Visual Studio Code.
- GitHub.

### Ejecución del programa
Para ejecutar la aplicación, abrir una terminal en la carpeta del proyecto y escribir:

```bash
python main.py
```

### Registro de eventos y errores
El programa genera el archivo `software_fj.log`, donde se registran los eventos importantes y los errores detectados durante la ejecución.
