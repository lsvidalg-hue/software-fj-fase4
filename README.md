## 1. Descripción del proyecto

Software FJ es una aplicación desarrollada en Python que permite gestionar clientes, servicios y reservas para una empresa que ofrece reservas de salas, alquiler de equipos y asesorías especializadas.

El proyecto aplica los principios de programación orientada a objetos y mecanismos de manejo de excepciones para controlar errores y garantizar la estabilidad de la aplicación.

## 2. Objetivo

Desarrollar un sistema integral que permita administrar clientes, servicios y reservas mediante clases, objetos, validaciones y mecanismos de control de errores.

## 3. Funcionalidades principales

- Registro y validación de clientes.
- Gestión de reservas de salas.
- Alquiler de equipos.
- Gestión de asesorías especializadas.
- Confirmación y cancelación de reservas.
- Procesamiento de reservas.
- Cálculo de costos con descuentos e impuestos.
- Control de disponibilidad de servicios.
- Registro de eventos y errores en archivos LOG.

## 4. Conceptos de programación aplicados

- Programación orientada a objetos.
- Abstracción.
- Herencia.
- Encapsulación.
- Polimorfismo.
- Clases abstractas.
- Métodos sobrescritos.
- Parámetros opcionales.
- Excepciones personalizadas.
- Validación de datos.
- Manejo de listas internas.
- Registro de eventos mediante LOG.

## 5. Manejo de excepciones

La aplicación incorpora diferentes mecanismos para identificar y controlar situaciones que pueden afectar su funcionamiento:

- try/except.
- try/except/else.
- try/except/finally.
- Encadenamiento de excepciones.
- Validación de datos incorrectos.
- Control de servicios no disponibles.
- Control de reservas no permitidas.
- Validación de cálculos y parámetros.

## 6. Pruebas del sistema

El programa simula 15 operaciones que permiten verificar diferentes escenarios:

- Registro válido e inválido de clientes.
- Creación de servicios.
- Validación de precios.
- Creación de reservas.
- Confirmación y cancelación.
- Procesamiento de reservas.
- Control de disponibilidad.
- Validación de parámetros.
- Cálculos con descuentos e impuestos.

## 7. Tecnologías utilizadas

## 8. Ejecución del programa

Para ejecutar el proyecto, abrir una terminal en la carpeta donde se encuentra el archivo principal y utilizar el siguiente comando:

```bash
python main.py
```

## 9. Registro de eventos

El sistema genera el archivo `software_fj.log`, donde se almacenan los eventos y errores relevantes durante la ejecución de la aplicación.
